# Технический мануал

Краткая техническая справка по проекту «Орбитальный пост наблюдения».
Пользовательские вопросы описаны в `manual.md` и `install.md`; здесь —
как всё устроено внутри.

---

## Стек

| Компонент | Технология |
|---|---|
| Язык | Python ≥ 3.10 (в репозитории проверено на 3.12) |
| Веб-фреймворк | FastAPI |
| ASGI-сервер | Uvicorn (`uvicorn[standard]`: httptools, websockets, watchfiles) |
| HTTP-клиент | httpx (асинхронный, с повторами — `backend/http_client.py`) |
| Расчёт орбит | sgp4 == 2.23 (версия зафиксирована: у новых выпусков другая сигнатура) |
| Конфигурация | python-dotenv (файл `.env` в корне, необязателен) |
| Фронтенд | Чистый HTML/CSS/JS без сборки; three.js и Chart.js из локальных копий в `frontend/vendor/` |

Сборка фронтенда и npm не используются: браузер получает статические
файлы напрямую от FastAPI.

---

## Как Python подключается ко всему проекту

Python — единственная исполняемая часть системы; фронтенд —
статические файлы, которые этот Python раздаёт.

### 1. Точка входа и цепочка запуска

```
start.bat / start.sh
  └─ создаёт .venv (если нет) и ставит зависимости
  └─ активирует .venv
  └─ python run.py
       └─ uvicorn.run('backend.main:app', host, port)
            └─ FastAPI-приложение из backend/main.py
```

`run.py` ничего не содержит, кроме вызова Uvicorn со строковой ссылкой
`'backend.main:app'` — Uvicorn импортирует модуль `backend.main` и берёт
из него объект `app` (экземпляр `FastAPI`). Параметр `reload=False`
задан намеренно: автоперезагрузка порождала бы лишние обращения
к внешним источникам.

### 2. Виртуальное окружение

`.venv/` в корне проекта. Активация добавляет `.venv\Scripts` в PATH,
после чего `python` и `pip` указывают на изолированный интерпретатор,
куда ставится `requirements.txt`. Все зависимости проекта — пять
прямых (fastapi, uvicorn, httpx, sgp4, python-dotenv); остальное —
их транзитивные пакеты. Системный Python используется только для
создания `.venv`; сам код проекта всегда исполняется из `.venv`.

### 3. Маршруты и раздача фронтенда

Все маршруты объявлены в `backend/main.py`:

- `GET /` — `FileResponse` на `frontend/index.html`;
- `app.mount('/css', StaticFiles(...))`, аналогично `/js`, `/vendor`,
  `/assets` — статические каталоги фронтенда;
- `/api/...` — REST-маршруты данных:
  - `/api/orbit/position`, `/api/orbit/track`, `/api/orbit/pass` —
    расчёты по TLE средствами sgp4 (`backend/providers/orbit.py`);
  - `/api/asteroids/{designation}`, `/api/status` и остальные —
    данные из внешних источников;
- CORS-посредник и HTTP-посредник (логирование) подключены
  через `@app.middleware`.

Таким образом Python «склеивает» три части: внешние источники данных
(исходящие запросы через httpx), расчёты (sgp4) и браузер (раздача
статики + JSON API). Фронтенд обращается к Python только через
`fetch` к `/api/...` (см. `frontend/js/api.js`).

### 4. Модули backend

```
backend/
  main.py         FastAPI-приложение, маршруты, оболочка ответов
  settings.py     Конфигурация: env-переменные поверх значений по умолчанию
  cache.py        Файловый кэш в .cache/ (JSON-файлы, TTL, переживает перезапуск)
  http_client.py  Общий асинхронный httpx-клиент: таймауты, повторы
  providers/
    orbit.py          Расчёт орбиты по TLE (sgp4)
    iss.py            Телеметрия МКС и экипаж (wheretheiss.at, open-notify)
    launches.py       Расписание запусков (thespacedevs)
    asteroids.py      Околоземные астероиды (JPL)
    space_weather.py  Космическая погода (NOAA SWPC)
    satellites.py     Каталог спутников и TLE (celestrak)
```

### 5. Конфигурация

`backend/settings.py` читает `.env` в корне через `load_dotenv(..., override=False)`,
то есть реальные переменные окружения имеют приоритет над файлом.
Ключевые параметры: `DASHBOARD_HOST`, `DASHBOARD_PORT`, `HTTP_TIMEOUT_SECONDS`,
`HTTP_RETRIES`, `CACHE_TTL_SECONDS`, `ISS_NORAD_ID`. Обязательных
настроек нет — без `.env` применяются значения по умолчанию
(`127.0.0.1:8000`).

### 6. Контракт ответов API

Каждый `/api/...` маршрут отвечает единой оболочкой:
признак успеха, данные, флаг «из кэша». При недоступности источника —
код 503 с описанием ошибки. Интерфейс обрабатывает все маршруты
одинаково, панели независимы друг от друга.

## Типичные технические ситуации

| Симптом | Причина и решение |
|---|---|
| `python -m venv` не работает, `No module named venv` | Системный `python` — старый (например, 2.7). Используйте лаунчер: `py -3.12 -m venv .venv` |
| Ошибка занятого порта 8000 | Задайте `DASHBOARD_PORT=8080` в `.env` или окружении |
| `ModuleNotFoundError: No module named 'fastapi'` | Запущено без активации `.venv`; активируйте окружение и повторите |
| Пустые рамки фото экипажа | Норма: не у всех экипажей есть фотографии, показываются инициалы |
