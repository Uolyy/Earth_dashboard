# Установка

Подготовка проекта к запуску: копирование, окружение, зависимости.
Сам запуск здесь не выполняется — для него в папке проекта есть
готовые сценарии (см. «Что дальше»).

Если файл открывает ИИ-агент в редакторе, ему передаётся задание:

> Клонировать репозиторий https://github.com/Uolyy/Earth_dashboard,
> прочитать файл install.md и выполнить всё, что в нём написано.

Агент подготовит проект к запуску: сервер при этом не запускается
и браузер не открывается.

---

## Что понадобится

| Что | Зачем | Как проверить |
|---|---|---|
| Python 3.10 или новее | язык, на котором написан сервер | `python --version` |
| Интернет | данные о космосе берутся из открытых источников | — |
| Git | скачать проект | `git --version` |

**Ключи и регистрация не нужны.** Проект работает с общедоступными
источниками, которые не требуют ни входа, ни оплаты.

Ничего больше устанавливать не надо: браузер, Node.js и редактор
для запуска не требуются.

---

## Шаг 1. Скопировать проект

```bash
git clone https://github.com/Uolyy/Earth_dashboard.git
cd Earth_dashboard
```

Если репозиторий закрытый, вместо этого нужно нажать на GitHub кнопку
**Code → Download ZIP**, распаковать архив и переименовать папку в
`Earth_dashboard`.

---

## Шаг 2. Создать окружение и поставить зависимости

```bash
python -m venv .venv
```

Окружение активируется командой:

- **Windows (PowerShell):** `.venv\Scripts\Activate.ps1`
- **Windows (CMD):** `.venv\Scripts\activate.bat`
- **macOS или Linux:** `source .venv/bin/activate`

Если PowerShell ругается на запуск скриптов, нужно один раз разрешить их:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Это займёт минуту и скачает около пяти библиотек.

---

## Что дальше

На этом подготовка закончена: сервер не запускался, браузер
не открывался. Запуск выполняется готовым сценарием из папки
проекта:

- **Windows:** файл `start.bat`;
- **macOS или Linux:** файл `start.sh`.

Сценарий сам проверяет окружение и пересоздаёт его, если оно
повреждено — например, после переноса проекта с другого компьютера.
Затем сценарий запускает сервер и открывает браузер с адресом вида
`http://127.0.0.1:8000` — это и есть дашборд.
Заново настраивать ничего не нужно: достаточно запускать `start.bat`
всякий раз, когда хочется посмотреть дашборд.

Остановить сервер: `Ctrl + C` в окне терминала, где он работает.

## Если что-то пошло не так

**`python` не найден, а `py` найден**
Вместо `python` можно использовать `py`. Это одна и та же программа,
просто с другим именем.

**Ошибка про занятый порт 8000**
Кто-то уже занял порт, чаще всего прошлое окно терминала.
Его нужно закрыть. Либо сменить порт:

```bash
# Windows (PowerShell)
$env:DASHBOARD_PORT=8080; python run.py

# macOS или Linux
DASHBOARD_PORT=8080 python run.py
```

Оговорка: `start.sh` эту переменную читает, а `start.bat` — нет,
он всегда открывает браузер на порту 8000. Если порт меняется,
`python run.py` нужно запускать вручную и открывать страницу
самостоятельно.

**Панели показывают ошибку, а страница открылась**
Так и должно быть: панели независимы друг от друга. Если не работает
один внешний источник, остальные продолжают работать. Нужно немного
подождать и обновить страницу — данные подтянутся.

**Окно запуска пишет «Жду сервер», браузер не открывается**
Сервер не смог подняться. Самая частая причина — виртуальное окружение,
скопированное с другого компьютера. `start.bat` проверяет его при
запуске и сам пересоздаёт, достаточно дождаться окончания установки
зависимостей. При ручном запуске нужно удалить папку `.venv`
и повторить шаг 2.

**`ModuleNotFoundError: No module named 'fastapi'`**
Не сработала активация окружения. Нужно вернуться к шагу 2 и выполнить
`pip install -r requirements.txt` заново.

**Пустые рамки вместо фотографий космонавтов**
Так и должно быть. Фотографии есть не у всех, у кого нет —
показываются инициалы.

## Что где лежит

```
run.py                     Запуск: python run.py
requirements.txt           Список зависимостей
install.md                 Этот файл
README.md                  Описание проекта
manual.md                  Как всё устроено внутри
issues.md                  Известные проблемы
start.bat, start.sh        Запуск в один клик

backend/                   Сервер: сбор данных и расчёты
frontend/                  Интерфейс: страница, стили, сцена
frontend/vendor/           Библиотеки three.js и Chart.js
.cache/                    Кэш ответов, создаётся сам. Удалять можно.
```
